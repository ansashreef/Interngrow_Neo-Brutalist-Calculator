# Neo-Brutalist Calculator

A modern Neo-Brutalist Calculator built using HTML, CSS, and JavaScript during my internship at InternGrow.

## Features

- Standard Calculator
- Programmer Mode
- Decimal, Binary & Hexadecimal Conversion
- Dark / Light Mode
- Responsive Design
- Modern Neo-Brutalist UI
- Real-time Calculations

## Technologies Used

- HTML5
- CSS3
- JavaScript
